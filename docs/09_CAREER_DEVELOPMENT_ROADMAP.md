## 📅 Monthly Milestone Breakdown

### Month 1: Fundamentals, Law, and Lab Architecture
* **Competencies:** TCP/IP networking, DNS resolution (`A`, `MX`, `TXT`, `CNAME`), HTTP headers, CFAA, GDPR, and privacy law basics.
* **Lab Action:** Deploy Windows 11 host with Kali Linux and Ubuntu VMs. Set up Obsidian evidence vault.
* **Target Certification:** CompTIA Security+ (Foundation).

### Month 2: Search Mastery & Metadata Forensics
* **Competencies:** Advanced search engine operators (Google Dorking), Wayback Machine archives, Certificate Transparency logs (`crt.sh`), and metadata extraction using `exiftool`.
* **Lab Action:** Complete Beginner Cases 01 to 05. Build the cryptographic SHA-256 evidence logging routine.

### Month 3: Automated Reconnaissance & Tool Suites
* **Competencies:** SpiderFoot CLI and web UI, theHarvester, Recon-ng workspace management, WHOIS historical pivot analysis.
* **Lab Action:** Complete Beginner Cases 06 to 10. Execute passive multi-source corporate reconnaissance.

### Month 4: Link Analysis & Entity Correlation
* **Competencies:** Maltego transform graphs, entity relationship mapping, social handle correlation (Sherlock/Maigret), corporate hierarchy tracing via SEC filings.
* **Lab Action:** Complete Intermediate Cases 11 to 15. Produce full-page graph visualizations of public organizations.

### Month 5: Threat Intelligence & Attribution Modeling
* **Competencies:** MITRE ATT&CK reconnaissance mapping, Diamond Model of Intrusion, Admiralty Code confidence weighting, indicator of compromise (IOC) reporting.
* **Lab Action:** Complete Advanced Cases 21 to 25. Author professional-grade threat intelligence briefings.

### Month 6: Capstone Project, Portfolio Publication, and Job Applications
* **Competencies:** Executive presentation, defensible intelligence report defense, portfolio curation.
* **Lab Action:** Complete the Final Capstone Investigation. Publish sanitized case studies on GitHub and your personal portfolio.
* **Target Roles:** Junior Threat Intelligence Analyst, Junior SOC Analyst, Information Security Specialist, OSINT Researcher.
